# 开放端口与访问检查

本项目 Web 服务默认监听 `5000` 端口，PostgreSQL 默认映射 `5432` 端口。

## 1. 检查服务监听

```bash
sudo ss -ltnp | grep :5000
```

看到 `uvicorn` 或 `python` 监听 `0.0.0.0:5000`，说明 Web 服务已经对外监听。

```bash
docker compose ps
docker compose exec postgres pg_isready -U myuser -d ptm_prod
```

看到 `accepting connections`，说明 PostgreSQL 可用。

## 2. 云服务器安全组

在云服务器控制台开放入站端口：

- TCP `5000`：网站访问端口。
- TCP `5432`：PostgreSQL 端口。公网部署时不建议对所有 IP 开放，只给自己的管理 IP 或内网开放。

如果已经配置 Nginx 反向代理到 80/443，则公网只需要开放 80/443，5000 可以只在服务器本机监听或仅内网访问。

## 3. Ubuntu 防火墙

如果服务器启用了 `ufw`：

```bash
sudo ufw status
sudo ufw allow 5000/tcp
```

如确实需要远程直连数据库，再按需开放：

```bash
sudo ufw allow from 你的管理IP to any port 5432 proto tcp
```

## 4. 访问验证

浏览器访问：

```text
http://服务器IP:5000
```

常用检查：

- 首页是否打开。
- `/login` 是否能打开登录页。
- `/admin/users` 登录管理员后是否能管理测试账号。
- `PTM_DOWNLOADS_ENABLED=false` 时，匿名用户是否看不到下载入口。
- 有下载权限的测试账号登录后，Raw Data 预览和下载按钮是否恢复。

## 5. 常见问题

- 页面打不开：先检查 `sudo systemctl status soybean-ptm --no-pager` 和 `sudo ss -ltnp | grep :5000`。
- 服务器本机能访问、外网不能访问：检查云服务器安全组和 `ufw`。
- 登录后下载仍不可用：确认测试账号勾选了 `Allow downloads`，并确认浏览器没有登录旧账号。
- 数据库连不上：确认 `docker compose ps` 中 postgres 正常运行，且 `.env` 中 `PTM_DB_HOST`、`PTM_DB_PORT`、`PTM_DB_USER`、`PTM_DB_PASSWORD` 与 Docker 配置一致。
