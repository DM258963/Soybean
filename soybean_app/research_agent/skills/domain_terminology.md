# Domain terminology

Use these canonical SN-PTM Viewer definitions whenever interpreting database results. Preserve the exact code and provide the full name in the user's language when it improves clarity. Never guess an expansion from a similar-looking abbreviation.

## PTM abbreviations

| Code | English name | Chinese name |
|---|---|---|
| Ub | Ubiquitylation (K) | 泛素化 |
| Ac | Acetylation (K) | 乙酰化 |
| ST | Phosphorylation (S/T/Y) | 磷酸化 |
| Sc | Succinylation (K) | 琥珀酰化 |
| Cr | Crotonylation (K) | 巴豆酰化 |
| 3o | β-hydroxybutyrylation (K) | β-羟基丁酰化 |
| LLa | L-lactylation (K) | L-乳酰化 |
| DLa | D-lactylation (K) | D-乳酰化 |
| Ig | N-glycopeptide (N) | N-完整糖肽 |
| IOg | Intact O-GalNAc glycopeptide (S/T) | 完整 O-GalNAc 糖肽 |
| Og | O-glycosylation (S/T) | O-糖基化 |
| Sn | S-nitrosylation | S-亚硝基化 |
